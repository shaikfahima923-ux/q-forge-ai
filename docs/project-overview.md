
# Q-Forge AI

## Project Description
An AI-powered question generation, verification, and examination platform.

## Main Features
- Upload study materials
- Generate questions using AI
- Verify questions and answers
- Review and approve questions
- Create mock examinations
- Conduct timed tests
- Calculate scores and generate reports

- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: Python, FastAPI
- Database: MySQL 8.0
- Database Connectivity: SQLAlchemy and PyMySQL
- Version Control: Git and GitHub
